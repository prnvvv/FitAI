# FitAI Knowledge Base

Drop curated fitness and nutrition source documents here (`*.pdf`, `*.txt`, `*.docx`).

These files are ingested into the shared `fitness_knowledge` Chroma collection by
`python -m scripts.ingest_knowledge` and are available to all users.

User-uploaded documents are never placed here. They are handled by the app and
stored in the per-user `user_documents` collection instead.
